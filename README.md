# 浙江26年模拟题分题型整理

浙江地区 2025-2026 学年高三/高二英语模拟卷题库，按题型整理成 Markdown。

## 内容

- 70 套浙江模拟卷
- 858 条已分类题目
- 题型覆盖：阅读理解（细节、推理、主旨、词义、观点态度、写作手法）、七选五、完形填空、语法填空、应用文写作、读后续写
- 三省联考、宁波九校附人工语义解析，审核版在 `题库分类/审核/`

## 目录

- `题库分类/`：按题型整理的 Markdown 题库
- `题库分类/整理进度.md`：70 套试卷的整理进度与缺答案情况

## 使用

配合 `homework_design` 技能自动调题：

```powershell
python homework.py retrieve --type "阅读-细节理解题" --count 5 --day S1
```

## 说明

- 原始试卷 PDF 不包含在本仓库中。
- 个别题目因答案页 OCR 丢失字符，答案标记为“待核对”。
